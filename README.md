# India Yoga Tourism

Sacred Himalayan Yoga Retreats, Ayurvedic Wellness Programmes, and Ashram Bookings.

## Features
- **User Guest Dashboard**: Managed bookings, PDF Vouchers, Payment Receipts, Travel Document Uploads, and Step-by-Step Journey Tracking.
- **Admin Management Panel**: Live Programme & Package Catalogue Editor, Booking Management, Blog CMS, and Custom Pages CMS.
- **Payments**: Razorpay & PayPal integration for domestic and international guests.
- **Authentication**: Clerk Authentication (`@clerk/nextjs`).
- **Database**: Prisma ORM with PostgreSQL.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```
